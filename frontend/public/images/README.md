# Photos for the website (optional)

Put your own photos here. The site uses them automatically; if a file is missing it simply
leaves that spot out (no broken images), so you can add them one at a time.

| File | Where it appears | Suggested size |
|---|---|---|
| `hero.jpg` | Home page, next to the headline | about 1200 x 900 px, landscape, under 300 KB |
| `crops/wheat.jpg`, `rice.jpg`, `maize.jpg`, `mustard.jpg`, `sugarcane.jpg`, `cotton.jpg` | Small thumbnail beside each crop in the results | about 200 x 200 px, square crop, under 40 KB each |

File names must be lowercase and match exactly (for example `crops/wheat.jpg`).

## Where to get photos you may use
- Photos you or your team took on a farm are the best choice (real, local, and no licence questions).
- Free sites such as Unsplash, Pexels or Wikimedia Commons. Read each photo's licence: some need
  credit. If a photo needs credit, add a line to the footer or the README.
- Do not copy images from random websites or Google results; they are usually copyrighted.
- Compress photos before adding them (for example with squoosh.app) so the site stays fast on mobile data.

For the hackathon logo, use the file the organisers provide and follow their usage rules.
